# A/C 配对训练恢复与 Table 1 扩展评测

本轮使用独立分支 `experiment/ac-table1-20261021` 和独立运行目录。前轮六个 20,000 步训练虽然写出了最终检查点，但逐步输入/目标哈希存在不一致，确认阶段门禁失败，未进入正式确认评测。这些检查点、日志及失败记录保留，不作为本轮有效结果，也不续训复用。

## 原因边界与执行变更

回放未能稳定复现原不一致，尚不能宣称定位了根因。本轮采取可直接验证的执行方式：同一随机种子的 B0/A/C 在一个进程内，每步只采样、加噪并执行一次 Mixup；为三个独立模型提供相同参考输入的独立副本。在每个模型更新前后分别计算实际输入/目标的 SHA256，同时要求模型步骤不消耗共享的数据随机数状态。任一步违反条件立即停止，并保存实际张量与随机数状态供诊断。

各模型保留独立优化器、调度器和 PFA 随机数状态。三份检查点均写入并校验成功后，才原子提交统一恢复清单。恢复只认共同提交步；评测前还复核所有训练步的参考/前/后哈希、冻结编码器检查、配置身份和最终检查点 SHA256。

科学参数沿用前轮：共同 B0 seed0 的 300,000 步 C0；batch16、FP32、CBSD432、128 像素训练块；fresh AdamW、学习率 1e-5 到 1e-6。A 为 rho=0.5 的深层相关 PFA，C 为权重 0.05 的结构损失。编码器参数冻结，BN 保留原训练行为。烟雾 200 步、筛选 5,000 步（seed100）、确认各 20,000 步（seed101/102），不启动新的 300,000 步完整训练。

## 两套评测各自保留

1. 原主终点：CBSD68 本轮留出的 48 张与 Kodak24，七条件、三个噪声种子。先在图像内部平均噪声重复，训练种子波动单独报告。所有数据都曾在前轮研究评测过，只能称本轮留出，不能称整个研究未见。
2. 追加历史基准：完整 CBSD68、Kodak24、McMaster、Urban100，共 210 张、15 个噪声条件。共同 C0 一份，加 B0/A/C 两个续训种子共七份权重，预期 22,050 条逐图结果。原始文件清单和 3,150 个唯一噪声输入必须与已上传的历史结果完全匹配；复用原历史噪声与 PSNR/SSIM 实现。完整 CBSD68 包含本轮开发的 20 张，追加结果单独保存，不替代主终点。

追加报告包括全部条件、完整 OOD 汇总和以下六个最高强度条目：

| 数据集 | 噪声条件 |
|---|---|
| CBSD68 | Gaussian sigma50 |
| Urban100 | Gaussian sigma50 |
| CBSD68 | Spatial Gaussian sigma55 |
| McMaster | Spatial Gaussian sigma55 |
| CBSD68 | Poisson alpha3.5 |
| Kodak24 | Salt-and-pepper density0.02 |

此前截图数字仅为用户给出的参考，其来源尚未独立核验。这里的“最高 OOD”指最高噪声强度，不是跨条件的最高均值；首页 G1 的 28.792 dB 是多条件汇总。盐椒与斑点噪声是项目扩展，不据此宣称复现论文的相同实现。

训练前可以读取原始图像核验输入哈希，该过程不运行模型、不产生去噪指标。正式确认评测等待全部最终检查点通过门禁。

## 执行与产物

入口为 `bash launch_ac_pipeline.sh`，自动执行既有模型契约、历史输入核验、新三组同步契约、真实 GPU 断点恢复、烟雾、筛选、确认、两套评测和报告。

每张 GPU 最多一个三模型训练进程；两个确认随机种子可分配给两张卡并行。GPU 准入连续采样两次，预留 8 GiB 外部任务余量，并给新三模型训练进程预留 8 GiB；真实 GPU 契约记录实际峰值。只观察其他用户进程，不修改其运行状态。

- `runs/ac/pipeline_state.json`：队列状态及固定协议。
- `runs/ac/<stage>/_triplet/seed<seed>/commit.json`：共同恢复提交点。
- `reports/ac/actual_triplet_contract.json`：真实模型与恢复验收。
- `reports/ac/historical_input_parity.json`：历史输入逐项一致性核验。
- `reports/ac/confirm/experiment_report.md`：原主终点。
- `reports/ac/table1/experiment_report.md`：历史完整基准与六项 Table 1。

本说明仅描述执行协议，不代表训练或评测已经完成。最终结论以各报告的完成标记、完整原始数据和验收记录为准。
