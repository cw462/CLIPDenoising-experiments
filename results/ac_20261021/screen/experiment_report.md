# A/C 联合实验：筛选阶段结果

生成时间：2026-10-21T06:34:21Z。完整评测 1,680 条，固定比较拼图 12 张。

B0：从 C0 重新建立优化器、仅 L1 的共同续训基线；A/B1：深层相关 PFA；C/B3：原始 PFA 加平滑结构损失。C0 为前轮 B0 seed0 的固定最终检查点，仅评测一次。

噪声种子 0/1/2 先在每张图、每个条件内部平均；Gaussian15 单独报告为 ID，其余六条件等权形成 OOD。各数据集单独计算，合并值对数据集等权，不能按图数混合替代。

CBSD68 前 20 张是本轮开发集，剩余 48 张与 Kodak24 是本轮保留集。本研究上一轮已评测完整 CBSD68/Kodak24，因此这些不是整个研究从未见过的测试数据。确认阶段在全部六组最终检查点固定后才访问保留集。

## 预设判断与负结果

预设工程判据：合并 OOD 平均 PSNR 至少增加 0.1 dB；确认阶段两个训练种子均同向增加；各训练种子的合并 ID 降幅不超过 0.05 dB。图像区间另列，不将其替代训练种子重复。
- B1：未达到单种子筛选数值门槛，仍需两个种子确认；OOD≥0.1 dB=False，所有种子 OOD>0=False，ID 保护条件=True。
  OOD 配对差值训练种子均值 -0.0166 dB；样本标准差 单种子不定义。
- B3：未达到单种子筛选数值门槛，仍需两个种子确认；OOD≥0.1 dB=False，所有种子 OOD>0=True，ID 保护条件=True。
  OOD 配对差值训练种子均值 +0.0058 dB；样本标准差 单种子不定义。

相对 B0，保留 140 条负 PSNR 差值（按训练种子×图像×条件，已平均噪声重复）。见 [negative_cases.csv](negative_cases.csv)，不删除退化样本。

## 证据范围

本轮是从同一个已训练 C0 继续训练的比较；不是独立从头重训。两个确认种子改变续训随机性，但共同初始化来自同一个 C0，不能宣称覆盖初始化不确定性。有限种子、开发集筛选和先前测试暴露均限制结论。

结构损失的训练标量不能与纯 L1 总损失直接比较。A/C 不改变推理网络的参数结构，结果只依据统一图像指标与固定样例判断，不从训练损失推导去噪效果。
