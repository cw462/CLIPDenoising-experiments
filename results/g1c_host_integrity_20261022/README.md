## 可直接核验的证据

独立单线程 C 程序只访问自己分配的 1 GiB 内存，以 `volatile uint32_t` 标量写入、读取九种模式。59.000 秒内累计验证 66,213,511,168 字节，记录 **7 次读写不一致，涉及 5 个虚拟地址**。全部为 `XOR 0x02000000`，即位 25 从 0 变成 1；其中两个地址跨不同模式重复出现异常。此程序完全不使用 Python、NumPy、PyTorch 或 CUDA。
